One architectural recommendation

I would split the platform into three major products:

1. Cloud Controller (SaaS) – the multi-tenant web platform where customers manage networks, employees, vouchers, billing, analytics, and policies.


2. Edge Gateway – software that runs on-site (mini PC, x86 appliance, or dedicated hardware) and actually performs routing, firewalling, QoS, captive portal, and traffic enforcement.

This separation is the same architectural principle used by many enterprise networking vendors because it scales well, works with multiple hardware vendors, and lets you continuously improve the cloud platform without replacing customer hardware.
